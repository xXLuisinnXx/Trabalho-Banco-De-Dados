# 🐾 Sistema de Banco de Dados para Petshop

Fala, pessoal! Este repositório contém os arquivos e scripts do nosso trabalho de Banco de Dados. Escolhemos o tema **Pet's (Petshop e Clínica Veterinária)** porque é um cenário muito comum no dia a dia, mas que por trás tem uma complexidade bem legal para modelar e criar relacionamentos.

## 💡 A Ideia do Projeto

A nossa ideia foi simular o sistema de um Petshop completo, que não faz apenas banho e tosa, mas também funciona como clínica veterinária e vende pacotes de assinatura. 

Para isso, o banco de dados foi pensado para gerenciar várias frentes do negócio:
* **Cadastro de Clientes e Pets:** Tutores e seus respectivos animais (com informações de raça, porte, etc.).
* **Equipe:** Divisão de funcionários entre veterinários (com CRMV), tosadores (com certificação) e atendentes.
* **Saúde e Histórico:** Controle de prontuários, vacinação com datas e doses, e prescrição de medicamentos.
* **Serviços e Pacotes:** Registro de atendimentos prestados (consultas, tosa) e um sistema de planos/assinaturas mensais para os pets.

## 🛠️ Tecnologias Utilizadas

* **SGBD:** MySQL
* **Modelagem:** Diagramas Conceitual, Lógico e Físico.

## 🚀 Como testar

Se quiser rodar o projeto na sua máquina, é só pegar os scripts `.sql` e executar no seu ambiente MySQL (pode ser via MySQL Workbench, DBeaver, ou linha de comando).
